Carry-On Luggage: one funny single-line excuse a developer gives when code breaks in production — a fresh turn on the oldest excuse in the book.

> It worked on my machine, so I shipped my machine to production — the bug came along as carry-on luggage.

## Run it

```sh
node main.ts
```

The program writes the excuse to `/output/entry.txt` (override with `OUTPUT_DIR`) and prints it to stdout. It refuses to run if the line is not 1–200 characters, so the gate can never see an invalid entry.
